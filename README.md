# 🥇 Goldfolio

Goldfolio adalah aplikasi web untuk membantu investor emas fisik mencatat, memantau, dan menganalisis investasi emas mereka.

Aplikasi ini mendukung pencatatan pembelian emas Antam, UBS, dan Galeri24 serta menampilkan nilai portofolio, average cost, dan profit/loss berdasarkan harga emas terbaru.

---

## ✨ Fitur

- 🔐 Login & Register
- 🪙 Manajemen Brand Emas
- 📝 Pencatatan Transaksi Pembelian
- 💰 Perhitungan Average Cost
- 📈 Profit & Loss
- 📊 Dashboard Portfolio
- 📅 Riwayat Harga Emas
- 📈 Grafik Perkembangan Portfolio

---

## 🛠️ Tech Stack

- Laravel 13
- PHP 8.3
- MySQL
- Tailwind CSS
- Vite

---

## 🚀 Cara Menjalankan Project

```bash
git clone https://github.com/naufdlh16/goldfolio.git

cd goldfolio

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate --seed

npm run dev

php artisan serve
```
